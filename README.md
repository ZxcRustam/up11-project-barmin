# Мир подкастов — Система управления каталогом и заказами

## 1. Название приложения
**Мир подкастов** — приложение для автоматизации продаж лицензий на подкасты. Система позволяет безопасно авторизовываться, просматривать каталог медиафайлов с гибкой фильтрацией, отслеживать доступные остатки лицензий на складе и динамически рассчитывать скидки.

## 2. Используемые технологии
* **Язык:** Python 3.13+
* **GUI (интерфейс):** PySide6
* **СУБД:** MySQL 8.0+
* **Драйвер БД:** mysql-connector-python

## 3. Назначение и основные функции
Приложение автоматизирует работу цифровой платформы подкастов. Основные функции:
* **Каталог подкастов:** отображение обложек медиафайлов, цен, студий-производителей и остатков доступных лицензий.
* **Авторизация:** вход по логину с автоматическим разграничением прав доступа на основе ролей (Гость, Покупатель, Менеджер, Администратор).
* **Поиск и фильтрация:** сортировка подкастов по цене, фильтр по идентификаторам категорий и поиск в реальном времени по названию или студии.
* **Подсветка:** визуальное выделение подкастов со скидкой более 15% (зелёный цвет цены `#2E8B57`) и временно отсутствующих позиций на складе (голубой фон карточки `#ADD8E6`).
* **Безопасное управление пулом:** использование `MySQLConnectionPool` для стабильного соединения и предотвращения утечек ресурсов.

## 4. Порядок подготовки БД и запуска
1. Установите СУБД MySQL и создайте базу данных `podcasts_db`.
2. Выполните SQL-скрипты для создания и заполнения таблиц (`users`, `products`, `stock_items`).
3. Проверьте правильность пароля доступа к СУБД в конфигурации класса `Database` (`database.py`).
4. Запустите приложение командой из терминала:
   ```bash
   python main.py
   ```
